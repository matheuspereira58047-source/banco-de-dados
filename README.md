# 💳 Sistema Bancário em Python

Este projeto utiliza Python com SQLite para criar um sistema simples de contas bancárias.
O código cria um banco de dados, adiciona contas, armazena informações como nome, saldo e CPF, além de listar os dados cadastrados no terminal.

## 🚀 Tecnologias Utilizadas

* Python
* SQLite3

## ⚙ Funcionalidades

* Criar banco de dados
* Criar tabela de contas bancárias
* Inserir dados no banco
* Listar contas cadastradas
* Manipulação básica de SQL

## 📂 Objetivo

Projeto desenvolvido para estudo de banco de dados, SQL e integração com Python.
